# 英语日记

自己部署、自己用的英语日记网站。写的时候不会的词直接写中文，写完让 AI 批改，再把生词收进生词本，把固定搭配和句式（比如 take sb. home）收进搭配本。

## 部署

不用下载源码，也不用自己编译。在服务器上新建一个目录，把 `docker-compose.yml` 下载进去，然后启动：

```bash
curl -O https://raw.githubusercontent.com/Playfullycat/diary/main/docker-compose.yml
```

```bash
docker compose up -d
```

镜像是 GitHub 自动构建的 `ghcr.io/playfullycat/diary:latest`，支持 x86-64 和 ARM64。

打开 `http://服务器地址:3000`，第一次访问会让你设置登录密码。

数据都在 `./data` 目录：

- `data/diary.db`：数据库
- `data/backups/`：本地自动备份

升级到最新版，`./data` 不会被动到：

```bash
docker compose pull
```

```bash
docker compose up -d
```

想用自己改过的源码，在源码目录里先构建同名镜像，再启动：

```bash
docker build -t ghcr.io/playfullycat/diary:latest .
```

如果部署在公网，建议在前面加一层 HTTPS 反向代理（Nginx、Caddy 等）。

## 首次配置

进入"设置"页：

1. **AI 模型**：选服务商，填 API 密钥和模型名称，点"测试连接"。用中转时选对应的协议，把接口地址换成中转地址。
2. **我的水平**：选一个大概的水平。默认是自动模式，批改满 3 篇后会按识别结果调整。
3. **备份**：填 AList 的 WebDAV 目录地址、用户名、密码，点"测试 WebDAV"，再点"立即备份"确认一次。

### AList 备份说明

- 地址形如 `https://你的域名/dav/网盘名/diary-backup`，目录不存在会自动创建。
- AList 用户需要开启"WebDAV 读取"和"WebDAV 管理"权限，建议单独建一个只能访问备份目录的用户。
- 如果 AList 和本站在同一台机器上，备份目录要选网盘存储，不要选本机存储。
- 每次上传后会校验文件是否存在、大小是否一致，失败会在首页提示，并在一小时后重试。

## 学习功能

- **复习**：生词本和搭配本里的内容会按记忆规律安排复习。每次选"忘了 / 有点模糊 / 记得"，记得越牢，下次出现隔得越久；首页会显示今天有多少个待复习。
- **错题本**：按类型统计批改里出现过的问题（时态、冠词、拼写……），点开能看到每一处原文、改法和解释。每篇日记只算最新一次批改。
- **回译练习**：在批改过的日记页点"回译练习"。AI 把修改版逐句翻成中文，你看着中文写回英文，再和修改版对照；拿不准的可以让 AI 点评。
- **练习题**："练习"页按错题本里你常犯的错误出选择题和填空题，做完当场判分并给解释。
- **进度**："进度"页有每周小结（写了几天、多少词、错误率、和上周的对比，可以让 AI 写一段总结）和三张图：每周写作量、错误率、水平估计。
- **阅读**："阅读"页按你当前的水平推荐读物，分成"正合适""轻松读""挑战一下"三档，可以标记想读、在读、读完。书单是人工整理的，在 `src/lib/books.ts` 里，可以自己增删。
- **写作日历**：首页显示最近 18 周哪些天写了日记、当前连续天数和最长连续天数。

回译、出题、周报小结只在你点按钮时才调用 AI，不会自动消耗额度。

## 备份与恢复

- **自动备份**：每天在设定的小时之后备份一次，先写本地，再上传 WebDAV。
- **保留策略**：在"设置 → 备份"里选保留多久（7 天、31 天、90 天、365 天或自定义天数，默认 31 天）。保留期内每天留最新的一份，更早的在下次备份时自动删除，最新的一份始终保留。
- **从网盘恢复**：在"设置 → 备份 → 从备份恢复"里点"一键恢复最新备份"，或点"选择其它备份"挑某一天的。新装的站点先填好 WebDAV 地址并保存即可恢复；备份加过密的话再填上加密密码。
- **加密**：设置了备份加密密码后，自动备份的文件是 `.zip.enc`（AES-256-GCM），只能在本站"从备份恢复"里用密码解开。密码忘了就解不开。
- **手动导出**：设置页"导出 ZIP 到本机"，下载的是未加密的 ZIP，里面有 `data.json`、每篇日记的 Markdown，以及生词本和搭配本的 CSV（可导入 Anki）。
- **恢复**：设置页上传 ZIP 或 `.zip.enc`。恢复会覆盖现有数据，恢复前会自动在本地另存一份。
- 备份文件不包含登录密码、API 密钥和 WebDAV 密码。

## 忘记登录密码

停掉容器，删除数据库里的密码记录后重新设置：

```bash
docker compose run --rm diary node -e "const {DatabaseSync}=require('node:sqlite');new DatabaseSync('/data/diary.db').exec(\"DELETE FROM settings WHERE key='password_hash'\")"
```

再次打开网站会回到"设置密码"页面，日记数据不受影响。
